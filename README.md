# 채용시장에서의 AI 역량 수요 분석

한국항공대학교 AI비즈니스론 수업 연구 프로젝트 (비상업적 학술 목적)

## 목적
사람인 채용정보 API를 활용해 채용공고 중 AI 관련 역량을 요구하는
공고의 비율을 기업 형태·산업·직무별로 비교하고, 제시 연봉 수준과의
관계를 통계적으로 분석합니다.

## 데이터 활용 범위
- 수집 데이터는 통계 분석에만 사용하며 재배포하지 않습니다.
- 분석 결과 보고 시 데이터 출처(사람인)를 명시합니다.
